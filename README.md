Project Overview

This project focuses on transforming raw heart disease datasets into meaningful insights using an interactive dashboard and visualization system.

The project analyzes factors such as:

Age

Blood pressure

Cholesterol levels

Heart rate

Lifestyle factors

The final visualizations are integrated into a web interface using Flask, allowing users and healthcare professionals to easily understand heart health patterns.

1. Data Collection & Extraction

2. Data Preparation

3. Data Visualization & Dashboard

Created multiple charts to analyze heart disease patterns.

Designed an interactive dashboard for easy exploration of data.

4. Storyboard Development

Built a narrative to guide users through the analysis.

Highlighted key findings and trends in heart disease data.

5. Web Integration (Flask)
